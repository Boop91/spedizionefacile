# Archivio documentazione

Questa cartella e' riservata a documenti che:
- erano utili in passato;
- non sono piu' documentazione canonica;
- devono comunque restare consultabili per storico o confronto.

Un documento entra in archivio quando il suo stato diventa:
- `obsoleto`
- `storico`
- `sostituito`

Ogni spostamento in archivio deve essere accompagnato da:
- motivo dello spostamento
- data
- documento canonico sostitutivo, se esiste
