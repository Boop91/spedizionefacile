# Architecture Decision Records

Questa cartella raccoglie le decisioni architetturali importanti del progetto.

Regola:
- se una scelta cambia struttura, confini, responsabilita', contratti o standard del progetto,
  va registrata in un ADR o almeno nel registro ADR.

Scopo:
- evitare che decisioni importanti vivano solo nelle chat o nella memoria del team
- permettere a chi arriva dopo di capire il "perche'"
